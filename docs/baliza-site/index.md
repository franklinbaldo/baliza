## Overview

The baliza-site project will provide:

- **Web Interface:** User-friendly interface for exploring PNCP data
- **Interactive Dashboards:** Visual analytics and insights
- **Query Interface:** Advanced search and filtering capabilities
- **Data Export:** Export filtered data in various formats

## Architecture

The baliza-site is designed as a separate repository from the CLI, allowing independent development and deployment. See [Architecture](../ARCHITECTURE.md) for details on the separation between the CLI and site components.

## Planned Features

- Interactive data visualization
- Advanced filtering and search
- Contract timeline views
- Organization profiles
- Statistical dashboards
- Data export capabilities

For more information, see the [Architecture documentation](../ARCHITECTURE.md).
